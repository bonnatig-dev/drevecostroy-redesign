# ДревЭкоСтрой — демо-редизайн v2 (Local Media)

Статический сайт HTML+CSS+JS без сборки. Открыть `index.html`.

## Страницы (по структуре текущего drevecostroy.by)
- `index.html` — главная (на текущем сайте это одностраничник): слайдер (4 фото, автосмена 6 с, плавный переход, точки и стрелки), о компании, типы проектов бань (6), «Хотите баню по вашему проекту?», комплектация (11 вкладок + 14 цветов), консультация инженера, «Наши бани снаружи» (17 фото, лайтбокс), 12 гарантий + преимущества, кредит/рассрочка, отзывы (6, полностью), «Как проходит работа» (7 шагов), квиз (10 вопросов, «Ваша скидка»), заявка, способы оплаты (ЕРИП), FAQ, контакты + Яндекс.Карта, футер.
- `project-*.html` — 6 карточек проектов (на текущем сайте — всплывающие окна «Подробнее»).
- `kniga.html` — страница /kniga/ («Получите книгу бесплатно»).
- `thankyou.html` — страница /thankyou/ («Спасибо за вашу заявку»).

- **Все тексты взяты с https://drevecostroy.by/ (главная, /kniga/, /thankyou/) 22.10.2026 без сокращений**, включая опечатки оригинала («белезну», «на на брус», «интерисуюшие», «Папортоник») — исправить по согласованию с клиентом.

## Шрифт и стиль
- altanhotel.ru (Tilda): `--t-headline-font` и `--t-text-font` = 'Arimo', Arial, sans-serif; начертание 400; заголовки UPPERCASE, letter-spacing 0.1px, 77px/1.05, 44px/1.2, 27px/1.4; текст 14px/1.45–1.55; кнопки-капсулы radius 30px. Своих @font-face нет.
- Подключён Arimo из Google Fonts (Apache License 2.0).
- Палитра по референсу: #000, #131313, #282828, белый; акцент — оранжевая кнопка #c8743a. Анимации появления при прокрутке, бренд altanhotel не копировался.

## Формы
Клиентская валидация (имя, телефон +375, e-mail, согласие), honeypot. Ничего не отправляется — показывается сообщение-заглушка.

## Карта
Яндекс.Карты, iframe `yandex.by/map-widget/v1/?text=Минск, ул. Козлова, 24А корпус 2&z=16`. Адрес реальный, с сайта; виджет работает **поиском по адресу** (без координат/ID организации) — при внедрении заменить на точную метку из конструктора Яндекс.Карт.
